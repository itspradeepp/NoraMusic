# Nora Music Technical Assessment

## Overview
This project is part of the technical assessment for Nora Music. The goal is to scrape the samples used in specific songs from WhoSampled and store the data in a structured format. The final output is provided as a CSV file due to technical difficulties with Google Sheets.

## Features
- Web scraping using Selenium
- Extracts song details and sample information
- Saves data into a CSV file for easy access and sharing

## Technologies Used
- Python
- Selenium WebDriver
- CSV
